Deep Learning Term Project

TFT Meta Deck Clustering and Action Advisor

A course project that applies autoencoders, convolutional board features, and feedforward networks to predict Teamfight Tactics placement and recommend the next strategic action.

YouTube Demo GitHub Repository

Project Content

Introduction

TFT decisions combine champions, traits, items, economy, augments, and positioning. This project treats those choices as high-dimensional game-state data.

Task and Method

The model compresses deck states with an autoencoder, clusters meta-decks, extracts board positioning features with convolutional kernels, and predicts final placement with a feedforward network.

Experiments

A reproducible synthetic match-log generator is included for grading. The same interfaces can be connected to Riot Developer API match logs.

Result Analysis

The advisor reports placement accuracy, Top 4 accuracy, nearest cluster, recommended action, and the expected placement improvement.

Conclusion

The most practical demo format is a local browser advisor that can also be captured as an OBS overlay while playing TFT.
