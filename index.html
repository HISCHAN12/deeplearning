TFT Recording Analysis and Deep Learning Advisor

An end-to-end prototype that applies representation learning, spatial board features, and a feedforward neural network to predict TFT placement and generate reference action recommendations.

Abstract

This project analyzes Teamfight Tactics game states with a NumPy autoencoder, convolution-style spatial features, and a feedforward placement classifier. It predicts final placement and Top 4 probability, then generates a reference action. An offline OpenCV pipeline samples a recorded match and creates a time-series HTML report. The current implementation is a research prototype trained on synthetic data, not a production game assistant.

1. Introduction

TFT combines composition, traits, items, augments, economy, level, and board positioning. Their non-linear interactions make the game a useful task for representation learning, spatial feature extraction, multi-class classification, and recommendation.

The objective is to demonstrate how deep learning concepts can turn a high-dimensional game state into understandable predictions and strategic reference information.

2. Task and Method

Tasks

  • Predict final placement from 1st to 8th.
  • Estimate the probability of finishing in the Top 4.
  • Recommend level up, reroll, save gold, equip an item, or reposition a carry.

Model Pipeline

  1. Multi-hot encoding for champions, traits, items, and augments.
  2. Autoencoder for an eight-dimensional deck embedding.
  3. K-means clustering for similar meta-deck groups.
  4. Fixed 3x3 convolution-style filters for the 4x7 board.
  5. Feedforward network with ReLU and Softmax outputs.

3. Recording Analysis

OpenCV samples a selected TFT recording at a configurable interval. The center board region is divided into a 4x7 grid. HSV saturation, brightness, Canny edge density, occupied-cell count, and frame-to-frame activity are converted into visual proxy features.

Each timestamp receives eight placement probabilities, a Top 4 probability, visual board strength, and a reference action with an explanation. The result is saved as JSON and an HTML timeline.

The analyzer does not recognize exact champions, items, health, or gold. Recommendations use estimated visual proxies and must not be interpreted as verified real-game strategy.

4. Experiments

The experiment uses 1,800 reproducible synthetic records with an 80/20 hold-out split. The generator defines controlled relationships between game state, action, board strength, and placement while preserving both Top 4 and bottom 4 examples.

5. Result Analysis

Exact placement is an eight-class problem and is harder than binary Top 4 prediction. The 67.8% Top 4 result indicates that the network recovers part of the controlled synthetic relationship between game state and outcome. It is not evidence of 67.8% accuracy on real TFT matches.

The recording pipeline produces changing probabilities and can output all five reference action categories. This verifies that video extraction, feature construction, prediction, and recommendation are connected end to end. Strategic correctness requires future evaluation using labeled real-match states.

6. Conclusion

The project demonstrates autoencoder representation learning, spatial feature extraction, regularized feedforward classification, clustering, and recommendation in one reproducible TFT prototype. Its main contribution is the complete implementation and analysis workflow rather than production-level game accuracy.

Future work includes Riot API data collection, champion and item detection, HUD OCR, a trainable CNN, temporal LSTM or Transformer modeling, and evaluation on real held-out matches.
